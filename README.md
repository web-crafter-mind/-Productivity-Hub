# 🚀 ProductivityHub

A modern all-in-one productivity dashboard built with pure HTML, TailwindCSS, and JavaScript.

## ✨ Features

- ✅ Smart Todo Manager
- ⏱️ Pomodoro Focus Timer
- 📝 Quick Notes System
- 📊 Productivity Analytics
- 💧 Water Intake Tracker
- 💰 Expense Tracker
- 🔐 Secure Personal Vault
- 🎵 Focus Music Integration
- 🌍 World Clock
- 🔑 Password Generator
- 🧠 AI Productivity Assistant
- 🎨 Sketch Pad
- 📈 Habit Tracker
- 🧮 Calculator
- 🔎 Smart Search Tools
